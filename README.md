Meandros is a horror rogue-like exploratory labyrinth game.

# Current Target
The Title Screen will be created. Player movement will be created allowing the player to move in any cardinal direction and a allow for jumping. Map generation should be created with the walls raised to the top. Basic moody lighting will be initialized. Finally, an enemy or item for the player to interact with. If the enemy touches the player, they should take damage, react in some way. If there is an item, it should benefit the player in some way whether it be strength, speed, or sight.  

General Flow: Player begins within the labyrinth and must explore the maze until they reach a ladder that lets them raise another floor. The goal is to escape the underground labyrinth before being defeated by an enemy. Throughout their exploratory journey, they'll be able to find items and encounter enemies that may attempt to harm them. If time prevails, we'd like to get some shop available for the player to shop with.
